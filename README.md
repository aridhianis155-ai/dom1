# Shopping Store

A simple shopping cart built with HTML, CSS, and vanilla JavaScript.

## Features

- Adjust product quantities and see the cart total update.
- View the number of items in the cart.
- Mark products as favorites.
- Remove products from the cart.

## Run locally

Open `index.html` in a web browser. Bootstrap and Font Awesome are loaded from CDNs, so an internet connection is needed for those styles and icons.

## Project structure

- `index.html` - shopping cart page
- `style/style.css` - page styles
- `js/script.js` - cart interactions
- `assets/` - product and action images
